# Decision records

Each file here holds the **relocated rationale** for a rule that also appears — in
one compressed paragraph — in [`AGENTS.md`](../../AGENTS.md) or
[`README.md`](../../README.md). The short version (the rule + the one-line
consequence of breaking it) stays resident where an agent or contributor reads
it; the narrative that earned it (what it defends against, which failure mode it
closes, what the wrong fix is) lives here so it is reachable without being
resident.

Follow a `→` link from an `AGENTS.md` bullet or a workflow comment to get here.
When you correct a claim that appears in more than one place, correct every copy
and check they agree — a rule split across files drifts otherwise.
